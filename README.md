# Food Sharing Web Application Frontend

This repository contains the frontend of a concept project for a food-sharing web application. Currently, it is a work in progress.

## Purpose
The main purpose of this project is to revise and reinforce concepts related to React development.

## Running the Project
To set up and run the project locally:

1. Install the dependencies:
   ```bash
   npm i
   ```

2. Start the project:
   ```bash
   npm start
